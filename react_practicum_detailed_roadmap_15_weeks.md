
# Подробный план изучения курса React в Яндекс Практикуме

Версия плана: 21 апреля 2026  
Основа: актуальная программа курса «React-разработчик» в Яндекс Практикуме

## Что я учёл при составлении плана

Этот план построен не как абстрактный «изучить React за 3 месяца», а как маршрут под реальную программу курса. На странице курса указано, что программа рассчитана на **3,5 месяца** и требует **12–15 часов в неделю**. В программе есть модули по **основам React**, **Vite**, **Storybook**, **Redux Toolkit**, **RTK Query**, **React Router**, **аутентификации**, **TypeScript**, **WebSocket**, **Vitest**, **Playwright**, **MSW**, **FSD**, **CI**, деплою и самостоятельный модуль по **ИИ**. В верхнем описании курса также встречаются **Jest** и **Cypress**: если эти инструменты будут в тренажёре, идти по материалам курса, а в личном проекте держать основной фокус на Vitest и Playwright. Также курс идёт спринтами и строится вокруг одного большого приложения. См. программу: https://practicum.yandex.ru/react/

## Сверка с официальной программой курса

В официальной программе отдельно отмечены темы, которые нужно держать в поле зрения по ходу маршрута:

- SPA и обзорное сравнение подходов React, Angular и Vue. Angular и Vue изучать глубоко не нужно, достаточно понять контекст.
- React DevTools, React DnD, CSS Modules, Storybook.
- Продвинутый React: мемоизация, конкурентный рендеринг, порталы, HOC, Error Boundaries.
- Роутинг и безопасность: React Router, History API, React Suspense, JWT, cookies, LocalStorage, защищённые маршруты.
- TypeScript: типизация `useContext`, `forwardRef`, `createRef`, Error Boundaries и HOC.
- WebSocket через Redux middleware или RTK Query.
- Тестирование: Vitest, Playwright, MSW, fixtures. Если в курсе будут Jest или Cypress, выполнять задания курса на них.
- Production readiness: Helmet, CI, GitHub Pages и деплой на сервер.
- Самостоятельный AI-модуль: промпт-инжиниринг, выбор инструментов, безопасность, этика, проверка ответов ИИ.

## Как работать по этому плану

- Занимайтесь **6 дней в неделю**, 1 день оставляйте на отдых или лёгкий повтор.
- Средняя нагрузка: **2–2.5 часа в день**.
- Если в Практикуме дедлайны жёсткие, ваш личный проект не должен мешать сдаче спринта. В такие дни приоритет всегда у заданий курса.
- У вас сильный технический бэкграунд: SQL, DE, Python. Это плюс. Но вам нужно сознательно прокачивать именно фронтенд мышление: композицию интерфейсов, UX, структуру компонентов, визуальную дисциплину, работу браузера.
- Каждый учебный день должен завершаться **маленьким измеримым результатом**: коммит, заметка, рефакторинг, закрытая тема, мини демо, карточка в трекере.

## Главные правила на весь срок

1. Не читать тему пассивно. После каждого блока сразу писать код.
2. Не копировать решения без разбора. Любой кусок кода вы должны уметь объяснить.
3. Каждый день делать коммит в Git.
4. Завести один файл `learning-journal.md` и ежедневно записывать:
   - что изучили
   - что осталось непонятным
   - какие ошибки были
   - какие 3 вывода сделали
5. После каждого спринта делать мини ревью:
   - что получилось
   - где застревали
   - чего не хватает по JS, CSS, Git, TypeScript
6. Не гнаться за идеалом в оформлении. Важнее пройти весь маршрут стабильно.
7. Любую новую сущность раскладывать на 4 вопроса:
   - что это
   - зачем это нужно
   - как работает
   - где ломается
